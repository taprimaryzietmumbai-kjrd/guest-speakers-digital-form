# Guest Speakers Digital Form

GitHub Pages front end for the Guest Speakers database.

Google Sheet ID: `1vdfpDuFDi2eyetU6-4DkUGI0_R2e8U9Cdc0HdvT6PT0`

Upload these files to the repository root:
- index.html
- style.css
- script.js
- README.md

Then enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

The Apps Script Web App URL will be inserted into `script.js` after the Google backend is deployed.

Do NOT store PAN, bank account, signatures, or submitted speaker data in GitHub.
